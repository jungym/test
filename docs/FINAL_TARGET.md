# Final Target — HAEN Hypercar Design Support AI

Concise orientation note for the project's end goal. This is **not** an
autonomous hypercar design system.

## Definition

A **human-reviewed, AI-assisted hypercar concept engineering support system**
that helps define, compare, screen, visualize, document, and govern HAEN
GT-1 / GT-1H / H2 architecture branches.

## It supports

- vehicle definition
- architecture branch comparison
- parametric packaging
- assumption-labelled mass / energy / dynamics screening
- supplier evidence management
- RFI generation
- forbidden-claim checking
- internal entry-validation dossier building

## It does NOT

It does not certify vehicles or finalize designs, and it makes no assertion of
road-legality, crashworthiness, production feasibility, supplier status, or
homologation readiness. All such judgements require human review and formal,
external process.

## Program branch structure

1. **GT-1 BEV** — baseline / realistic first digital-package branch.
2. **GT-1H 700bar H2** — hydrogen halo branch; **screening branch only**.
3. **GT-1H LH2** — liquid-hydrogen **watch branch**; Hylium Level 1 **RFI
   candidate only**; **not** baseline; supplier status **unconfirmed**.

## Long-term modules (orientation only — not all built yet)

Governance & Claim Control · Vehicle Definition Core · Design Space Explorer ·
Packaging Lab · Mass & Energy Model · Low-Fidelity Simulation · Design
Visualization · Supplier Evidence & RFI · Report Builder · Streamlit Dashboard.

Build proceeds one approved review-gate item at a time; see
`docs/reviews/REVIEW_GATE_2_SCOPE.md` for current scope.
