# 금지 클레임 거버넌스 — 한국어 안내 (Claim Governance, Korean)

HAEN Hypercar Design Support AI는 **사람이 검토하는 AI 보조 컨셉 엔지니어링 지원
시스템**입니다. 자율 차량 설계, 인증, 양산 CAD, 외부 공개 시스템이 아닙니다.
모든 산출물은 내부 검토용이며 사람의 검토가 필요합니다
(`human_review_required: true`, `external_release_allowed: false`).

## 검사기 동작 (How the checker works)

- **하드 게이트** (`check_text` / `assert_clean`): 생성된 모든 문서(도시에,
  레디니스, RFI, 리포트)에 적용되는 권위 있는 검사입니다. 위반 시 산출이
  차단됩니다.
- **어드바이저리 시맨틱 레이어** (`semantic_risk_scan`): 경고 전용입니다. 하드
  게이트를 약화시키지 않으며, 사람 검토 후보만 표시합니다.
- **세이프 섹션** (`claim-safe-section` 마커): 이 저장소의 `docs/` 문서에서만
  유효합니다. 생성 산출물에는 절대 포함될 수 없으며, 검사·테스트로 차단됩니다.

## 안전한 표현 (Safe framings — 권장)

다음의 **부정/미확정 명사형** 표현은 검사를 통과합니다:

- 도로 주행 적법성: **미평가** (road-legality not assessed)
- 인증 상태: **미평가** / 인증 **미완료**
- 충돌 안전성: **미평가** / 충돌 안전성 **미검증**
- 양산성: **미평가** / 양산 **불가 여부 미판단**
- 공급사 상태: **미확정** (supplier status unconfirmed)
- 설계 상태: **탐색 진행 중** / 설계 **미완료**
- 디지털 트윈: **검증된 디지털 트윈 아님**

## 부정형 처리 (Negation handling)

한글에는 정규식 단어 경계가 없으므로 패턴은 긍정 동사(확보/보장/입증/완료/가능/
확정/취득/획득/통과)에 앵커링됩니다. 따라서 `미평가`, `미완료`, `미검증`,
`안 됨`, `불가` 같은 부정형 안전 표현은 차단되지 않습니다.

## 한계 (Limitations)

- 검사기는 패턴 기반(lexical)이며, 목록을 우회하는 의미상 암시까지 잡아내지
  못합니다. 시맨틱 레이어는 보조이며 완전하지 않습니다.
- 사람 검토가 항상 최종 단계입니다.
